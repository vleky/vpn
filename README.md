# NeuroScan

Демонстрационный лендинг для конкурсного кейса фестиваля «ПрофГоризонт».

Откройте `index.html` в браузере или разместите репозиторий на любом статическом хостинге. Сборка и зависимости не требуются. Шрифт Manrope загружается через Google Fonts; без сети используется системный шрифт.

Страница включает адаптивную верстку, сравнение снимка с условной разметкой, переключатель для государственных и частных клиник и демонстрационную форму.

## Важно перед реальным запуском

- Форма не отправляет и не сохраняет персональные данные. Для приема заявок нужен защищенный серверный обработчик и документы по обработке персональных данных.
- Клинические, экономические и регистрационные показатели взяты из условий кейса и не подтверждены приложенными документами.
- Снимки для сравнения предоставлены автором проекта. Разметка на втором изображении демонстрационная; диагноз по ней не устанавливается.
